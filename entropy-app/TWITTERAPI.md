# Підключення twitterapi.io

Адаптер підготовлено за документацією провайдера, перевіреною 17 листопада 2026 року. У цій версії його перевірено на змодельованих відповідях; реальні платні запити не запускалися. API-ключ у проєкті відсутній.

## Що вже реалізовано

- `twitterapi.mjs`: серверний клієнт пошуку згадок та отримання постів за точними ID, до 50 за запит. Тільки два методи читання, фіксований домен провайдера, таймаут, обробка помилок без виведення ключа.
- `collect-twitterapi.mjs`: окремий ручний збір за денними вікнами UTC. Дедуплікація за ID, ліміт кількості запитів, зупинка за некоректної пагінації. За замовчуванням показує лише план, без доступу до мережі.
- Результат — JSON для кнопки «Імпортувати дані» в кабінеті. Ключ до цього файлу не потрапляє.
- Власні пости офіційного акаунта та звичайні репости не зараховуються як внесок кріейторів. Цитування з власним постом можуть бути кандидатами. Релевантність і якість залишаються предметом перевірки.
- Під час імпорту рішення переносяться з `sample:<handle>` на справжній X ID лише за збігом точного ID того самого поста. Збігу імені недостатньо. Суперечливий перехід відхиляється до зміни даних.

## Ручна перевірка плану

Потрібен Node.js 20+; додаткові пакети не потрібні. У каталозі вихідного проєкту:

```sh
node collect-twitterapi.mjs --handle entropyIO --start 2026-11-01 --end 2026-11-02 --max-requests 5
```

Ціль, підтверджена користувачем, — `@entropyIO`; вона також встановлена за замовчуванням у збирачі. Кінцева дата — виключна межа UTC. Запит шукає прямі згадки цього акаунта; це ще не охоплює всі текстові згадки назви, посилання чи тематично пов’язані пости.

Після налаштування `TWITTERAPI_IO_KEY` у захищеному серверному середовищі розробник може виконати один збір:

```sh
node collect-twitterapi.mjs --handle entropyIO --start 2026-11-01 --end 2026-11-02 --max-requests 5 --output ../twitterapi-snapshot.json --run
```

Не передавайте ключ аргументом команди й не вставляйте його в HTML. Збір не запускається при відкритті кабінету. Вихідний файл не перезаписується: для нового запуску потрібне нове ім’я або свідоме видалення попереднього файла.

Між запитами є пауза 5,1 секунди; повтори після помилок вимкнено. `max-requests` обмежує кількість викликів, а не суму в доларах: вартість залежить від отриманих даних і тарифу. Ліміт, помилка або порожня сторінка не означають, що згадок більше немає. `meta.collection` зберігає кількість викликів, часові вікна та причину зупинки. Навіть вичерпаний курсор не є доказом повного покриття X.

## Визначення метрик

| Провайдер | Кабінет |
|---|---|
| `viewCount` | Перегляди (`impressions` у внутрішній формулі) |
| `likeCount` | Лайки |
| `retweetCount` | Репости |
| `quoteCount` | Цитування |
| `replyCount` | Коментарі, сирий лічильник |
| `author.id` | Постійний текстовий X ID автора |
| `author.followers` | Поточна кількість підписників |

Відсутній лічильник зберігається як `null`, а не нуль. Перегляди — накопичені значення на момент збору для постів, створених у вибраному періоді; це не приріст саме в цьому місяці, не унікальна аудиторія й не доказ органічності. Smart Followers та Smart Engagement залишаються невизначеними до збору зв’язків і змістовної оцінки. Блакитна галочка не означає вагу довіри 1.

`tweetsByIds()` повертає `missingIds`: відсутній пост не видаляється автоматично і не отримує нульові метрики. Причина відсутності може бути різною. Потрібні повторна перевірка та політика проєкту.

## Що потрібно для постійної роботи

У цю локальну версію ще не входять сервер із постійним процесом, спільна база, автоматичний розклад, історія знімків, захищений вхід команди та кріейторів. Для запуску потрібні точний акаунт і правила пошуку, серверне налаштування ключа та місце роботи сервера. Методи отримання аудиторії, відповідей та цитувань для smart-оцінок описані нижче, але ще не підключені до збирача.

Після цього варто окремо оновлювати нові згадки й метрики вже знайдених постів, зберігати попередні значення, показувати час останнього успішного оновлення та пропуски. Бан має залишатися рішенням модератора, а не наслідком тимчасової помилки API.
